Factory Inventory Management System

A demo full-stack application: a Vue 3 single-page app talking to a Python FastAPI service that serves mock data loaded from JSON files into memory. There is no database, no authentication, and no persistence.

Data flow: a filtered dashboard request

  1. User changes a filter in FilterBarTime period, warehouse, category or order status.
  2. Shared state updates in useFiltersModule-level refs act as a singleton, so every view sees the same filter values.
  3. The view watches the filters and calls api.jsgetCurrentFilters() maps the period to month; values of "all" are dropped from the query string.
  4. Axios sends GET /api/dashboard/summary?warehouse=…&month=…Direct to localhost:8001; there is no Vite proxy, and CORS is open.
  5. FastAPI filters the in-memory listsapply_filters matches warehouse, category and status; filter_by_month matches a month or a quarter on order_date.
  6. The backend aggregates and validatesTotals and counts are computed in Python; list endpoints are validated against Pydantic response models.
  7. The view stores raw data in refs and derives the UI in computed propertiesKPIs, charts and tables re-render reactively; currency formatting follows the locale.

Observations

Tasks API has no backendApp.vue calls getTasks, createTask, deleteTask and toggleTask, but main.py defines no /api/tasks routes, so those requests return 404.
Purchase-order endpoints are missingapi.js defines createPurchaseOrder and getPurchaseOrderByBacklogItem, with no matching routes; nothing calls them yet. purchase_orders.json is empty.
Backlog.vue is not routedThe view exists but is not registered in main.js or linked in the nav.
Dashboard backlog count ignores filterstotal_backlog_items always counts every backlog item, and total_orders_value is not rounded.
API base URL is hard-codedhttp://localhost:8001 appears in api.js and again in Reports.vue; there is no environment config or dev proxy.
